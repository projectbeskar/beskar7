# Adopters of Beskar7

This file lists organizations that use Beskar7. It shows prospective users where the project is running, and it helps
the maintainers understand how the project is used.

## Adopter types

| Type | Description |
| ---- | ----------- |
| End user | Uses Beskar7 to run its own infrastructure, and does not sell it as a service |
| Service provider | Offers Beskar7 as a core part of a service, such as a managed platform or bare-metal cloud |
| Project | An open source project that integrates with or depends on Beskar7 |
| Vendor | A commercial project that embeds Beskar7 in its core offering |
| Consultancy | Helps other organizations build solutions with Beskar7 |

**Adoption levels:** Production, Dev/Test, Trialing, Evaluating.

## Adding your organization

Open a pull request that adds a table to the list above, or a row if the table already exists. Stating the type and
adoption level is encouraged but not required:

```markdown
| Organization | Type | Adoption level | Description |
| ------------ | ---- | -------------- | ----------- |
| [Example Corp](https://example.com) | End user | Production | Provisions the bare-metal workers of its Kubernetes clusters |
```

Please add only an organization you are authorized to speak for. If yours needs to stay anonymous, list its industry
instead of its name, for example "European telecommunications provider".
