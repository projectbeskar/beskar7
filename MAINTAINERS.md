## What maintainers do

- Review and merge pull requests.
- Cut releases and keep the [supported versions](SECURITY.md#supported-versions) current.
- Handle security reports, as described in [SECURITY.md](SECURITY.md).
- Handle reports under the [Code of Conduct](CODE_OF_CONDUCT.md).

## Becoming a maintainer

Maintainers are drawn from people who contribute to the project over time, through code, reviews, documentation or
testing on real hardware. If you would like to become a maintainer, open an issue or ask an existing maintainer. The
current maintainers decide, and a new maintainer is added by a pull request to this file.

## Emeritus maintainers

Maintainers who step back from the project are recognized here. There are none yet.
